# ربات تحلیل‌گر کریپتو برای تلگرام

این ربات کاملاً **رایگان** روی GitHub Actions اجرا میشه (نیازی به VPS یا سرور نداری) و هر ۱۲ ساعت
یک‌بار، ۵۰ کوین برتر بازار رو از نظر تکنیکال، حجم، اخبار و احساسات بازار (StockTwits) تحلیل می‌کنه
و گزارش رو تو تلگرام برات می‌فرسته.

## راه‌اندازی (کاملاً از موبایل قابل انجامه)

### ۱) ساخت ربات تلگرام
1. تو تلگرام برو سراغ [@BotFather](https://t.me/BotFather)
2. دستور `/newbot` رو بزن و اسم و یوزرنیم دلخواه بده
3. یه **توکن** بهت میده، مثل: `123456:ABC-DEF...` — اینو نگه دار (`TELEGRAM_BOT_TOKEN`)

### ۲) گرفتن Chat ID
1. با ربات جدیدت یه پیام بفرست (هر چیزی، مثلاً "سلام")
2. تو مرورگر برو به این آدرس (به‌جای `<TOKEN>` توکن خودتو بذار):
   `https://api.telegram.org/bot<TOKEN>/getUpdates`
3. تو جواب، دنبال `"chat":{"id":` بگرد — همون عدد `TELEGRAM_CHAT_ID` توئه

### ۳) آپلود کد تو گیت‌هاب (از موبایل)
1. یه ریپوی جدید تو [github.com](https://github.com) بساز (مثلاً `crypto-signal-bot`) — می‌تونی مستقیم از مرورگر موبایل این کارو کنی
2. فایل‌های این پروژه (`main.py`, `requirements.txt`, `.github/workflows/run-bot.yml`) رو
   از طریق گزینه **Add file → Upload files** تو گیت‌هاب آپلود کن (مسیر پوشه‌ها رو رعایت کن،
   یعنی فایل workflow باید تو مسیر `.github/workflows/run-bot.yml` باشه)

### ۴) اضافه کردن Secret ها
1. تو ریپو برو به: **Settings → Secrets and variables → Actions**
2. دو تا Secret جدید بساز:
   - `TELEGRAM_BOT_TOKEN` → توکن مرحله ۱
   - `TELEGRAM_CHAT_ID` → آی‌دی مرحله ۲

### ۵) تست اجرا
1. برو به تب **Actions** تو ریپو
2. روی workflow با اسم "Crypto Signal Bot" کلیک کن
3. دکمه **Run workflow** رو بزن تا یه بار دستی تست بشه
4. اگه همه‌چیز درست باشه، چند دقیقه بعد پیام تو تلگرامت میاد

بعد از تست موفق، دیگه لازم نیست کاری کنی — خودش هر ۱۲ ساعت (ساعت ۰۰:۰۰ و ۱۲:۰۰ UTC) اجرا میشه.
اگه می‌خوای زمانش رو عوض کنی، خط `cron` تو فایل `run-bot.yml` رو ویرایش کن.

## نکات مهم

- **دقت تحلیل**: این یه سیستم rule-based (قانون‌محور) ساده‌ست، نه هوش مصنوعی پیش‌بین. هیچ ابزاری
  نمی‌تونه سود رو تضمین کنه — همیشه با ریسک خودتون تصمیم بگیرید.
- **StockTwits به‌جای توییتر**: چون API رسمی X گرونه، از StockTwits (رایگان) برای احساسات بازار
  استفاده شده. اگه بعداً بودجه داشتی، می‌تونیم به X API وصلش کنیم.
- **محدودیت‌های رایگان**: CoinGecko، Binance، و StockTwits همه نسخه رایگان و بدون کلید API استفاده
  می‌کنن. اگه در آینده rate-limit خوردی (خطای 429)، می‌تونیم delay بین درخواست‌ها رو بیشتر کنیم.
- **گسترش**: می‌تونی راحت آستانه‌های امتیازدهی (`score_coin` تو `main.py`) رو مطابق سبک معاملاتی
  خودت تغییر بدی.

## ارتقاهای پیشنهادی بعدی
- اضافه کردن تحلیل احساسات خبر با AI (به‌جای فقط match کلمه)
- اتصال به X API رسمی وقتی بودجه داشتی
- اضافه کردن اندیکاتورهای بیشتر (Bollinger Bands, Fibonacci)
- ذخیره تاریخچه امتیازها برای دیدن روند تغییر سیگنال در طول زمان
